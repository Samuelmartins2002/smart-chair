# Smart Chair

Cadeira de rodas assistiva controlada por gestos da mão (Projeto Integrador V, UNIPAMPA).

## Componentes
- `app/` — aplicativo Flutter (Android/iOS) de monitoramento
- `pi/` — servidor Python (Raspberry Pi 3)
- `firmware/` — firmware do ESP32 na pulseira (MPU6050)
- `tools/` — scripts de simulação
- `docs/` — protocolo e documentação
